# Arrow To-Do

A simple Python CLI-based To-Do app for Windows.

Created as a Teachers' Day gift for **[NC Sir (C.S. Teacher)](https://www.youtube.com/@ComputerTopicsInBangla)** by Shayak.

## How to Run

Run:

```text
APP.bat
```

or run:

```text
python App/app.py
```

to start the application.

## Background Mode

To run Arrow To-Do in the background
*(It will run without opening a window)*, run:

```text
BG.bat
```

or:

```text
python App/bg.py
```

### Automatic Startup

To make Arrow To-Do start automatically when Windows starts, run:

```text
Lastup.bat
```

After setting it up, the background process will start automatically when the PC starts.

If `Lastup.bat` has not been set up, you need to manually run `BG.bat` or:

```text
python App/bg.py
```

after turning on the PC.
